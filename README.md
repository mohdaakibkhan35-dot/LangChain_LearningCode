# LangChain Basics – Hands-on Learning Repository

Welcome to the **LangChain Basics Learning Repository!** 🚀

This repository contains beginner-friendly Python code examples to help developers understand the fundamentals of **LangChain and Large Language Model (LLM) applications**.

If you are starting your journey with LangChain or want to understand how its different components work, this repository will help you learn through practical examples.

## 🎯 What You'll Learn

This repository covers the following LangChain concepts:

| # | Topic | Description |
|---|---|---|
| 1 | LLMs | Understanding Large Language Models and their integration |
| 2 | Chat Models | Working with conversational AI models |
| 3 | Embedding Models | Converting text into numerical vector representations |
| 4 | Document Loaders | Loading documents from different sources |
| 5 | LangChain Tools | Understanding and using tools with LLMs |
| 6 | Output Parsers | Structuring and formatting LLM responses |
| 7 | Prompts | Creating and managing prompt templates |
| 8 | Retrievers | Retrieving relevant information from documents |
| 9 | Text Splitting | Splitting large documents into smaller chunks |
| 10 | Vector Databases | Storing and searching vector embeddings |

## 📚 Learning Objectives

By exploring this repository, you will understand:

- How LLMs and Chat Models work with LangChain.
- How to generate embeddings from text.
- How to load documents from different sources.
- How to create and use prompt templates.
- How to integrate tools into LLM applications.
- How to parse structured LLM outputs.
- How text splitting works and why it is important.

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/LangChain-Basics-Learning.git
```

### 2. Navigate to the Project

```bash
cd LangChain-Basics-Learning
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it:

**Windows:**
```bash
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure API Keys

Some examples may require API keys depending on the LLM provider or embedding model being used.

Create a `.env` file and configure the required environment variables.

```env
OPENAI_API_KEY=your_api_key_here
```

Never upload your actual API keys, passwords, or secrets to GitHub.
